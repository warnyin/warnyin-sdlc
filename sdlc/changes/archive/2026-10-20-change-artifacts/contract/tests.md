# Test contract — change-artifacts
<!-- cap:60 · written BEFORE code. This is the deterministic half of the contract with the AI; failing tests are generated from this table. -->

Golden basis = first 12 hex of sha256 over each unfenced `## Design` / `## Delta:` section (heading + body to the next unfenced `## `), each `trimEnd`-ed, `\n`-joined, after CRLF→LF — computed by the test, never read from the code. Export: `artifactBasis(text)` in `lib/artifacts.mjs`. Every refusal row also runs a valid name on the same fixture (exit 0) as its positive control. Symlink rows skip only when the OS refuses to create one; the Windows junction case never skips.

## Out of scope (explicitly untested + why)
- Stage offers, config policy, kind catalog, publish sync — groomed out (follow-ups to #12).
- Two concurrent `artifact` runs on one change — no lock, like park; a stamp is a human/agent step, and a lost line is restored by re-running it.
- A symlink swapped between check and write — `writeFileContained` opens with `O_NOFOLLOW` where the OS has it (change-parking spec); win32 has none, so there it is check-then-write (Design); row 25 pins that the CLI writes only through it.
- Two lines for the same file in validate — each line is checked on its own; the command refuses to stamp one (row 28).
- Artifact content — never opened by validate, by design.
