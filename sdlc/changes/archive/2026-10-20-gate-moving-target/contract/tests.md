Every row reads a payload file from `PKG_ROOT/payload`. Anchors, each asserted NON-EMPTY before use: `contract-evals.md` — its `## Rubric` and `## Pass bar` sections, split on raw `\n- ` into bullets (never `oneLine` across bullets); `verify.md` — the `**Evals (non-deterministic)**` bullet of step 1; `review.md` — step 1 (it ends at `1c.`); `sdlc-evaluator.md` and `SKILL.md` — the whole file / its evals.md section. Every rule is pinned as an EXACT sentence (one `RULES` table in the test, compared after whitespace is collapsed) inside its anchor — not by regex over meaning: inverting any word of a rule breaks the equality, so the "not:" wordings below are caught by construction. Old wording that would contradict a rule is pinned absent as literal text (`FORBIDDEN`). A rule's wording changes only by editing `RULES` and the payload together. Not caught: a second, contradicting sentence added beside an intact rule.
